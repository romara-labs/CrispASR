# Shadow Orchestration Plan

## Strategy

Dynamic agents are temporary, task-specific workers created on demand.
Each agent operates under a formal contract that defines its boundaries,
evidence requirements, and disposal.

## Active Agents

*(none)*

## Orchestration Rules

1. No agent creation without a base plan.
2. Every agent has a disposal strategy.
3. Evidence is required before completion.
4. Archived agents are preserved for audit.
